## 🚀 Deploy to Vercel

```bash
# Install Vercel CLI globally
npm install -g vercel

# Login
vercel login

# Deploy to production
vercel --prod
```

Or push to GitHub and import at [vercel.com](https://vercel.com)

## 📊 Analytics (Optional)

Enable by adding to Vercel environment variables:
```
VITE_ANALYTICS_ENABLED=true
VITE_ANALYTICS_PROVIDER=your-provider
```

## 📧 Email Capture (Optional)

Configure by adding to Vercel environment variables:
```
VITE_EMAIL_PROVIDER=your-provider
VITE_EMAIL_API_KEY=your-api-key
```
